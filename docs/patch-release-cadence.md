# Patch Release Cadence

Date: 2026-01-30

## Release Frequency
- Regular patch window: biweekly
- Emergency patches: as needed for incidents or critical bugs

## Approval Checklist
- Change scope is patch-only (no new features)
- Backward compatibility verified
- No schema redesigns or data removals
- Audit logging and monitoring unchanged
- Rollback plan documented and tested
- Governance rulebook compliance confirmed

## Rollback Requirement
- Every patch must have a verified rollback path
- Reversible migrations or safe mitigation required
- Post-release validation checklist completed
